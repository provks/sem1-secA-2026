## Common Programming Naming Cases

* **camelCase**: The first word is lowercase and each subsequent word starts with a capital letter (e.g., `userProfileName`). Used heavily for variables and functions in JavaScript and Java.
* **PascalCase**: Every word starts with a capital letter, with no spaces or separators (e.g., `UserProfileManager`). Used for classes, interfaces, and components.
* **snake_case**: All lowercase letters with words separated by underscores (e.g., `user_profile_name`). Commonly used in Python and SQL databases.
* **kebab-case**: All lowercase letters with words separated by hyphens (e.g., `user-profile-name`). Used in URLs, CSS classes, and HTML data attributes.
* **CONSTANT_CASE** (or **Screaming Snake Case**): All uppercase letters with words separated by underscores (e.g., `MAX_RETRY_LIMIT`). Used for global constants or configuration flags.

# Common Programming Naming Cases -:

**camelCase**: The first word is lowercase and each subsequent words starts with a capital letter (e.g., ***userProfileName***).
It is used for variable and function in *JavaScript* and *Java*.
Here you can check more example of *camelCase* [camelCase](https://developer.mozilla.org/en-US/docs/Glossary/Camel_case).
***

**PascalCase**: Every words starts with a cpaital letter, with no spaces or separators (e.g., ***UserProfileManager***).
It is used mainly for classes, interfaces, and components.
Here you can check more example of *PascalCase* [Pascalcase](https://realpython.com/ref/computer-science-glossary/pascal-case/).
***

**snake_case**: All lowercase letters with words separated by underscores (e.g., ***user_profile_name***).
Used in *Python* and *SQL Databases*.
Here you can check more example of *snake_case* [snake_case](https://developer.mozilla.org/en-US/docs/Glossary/Snake_case).
***

**kebab-case**: All lowercase letters with words separated by hyphens (e.g., ***user-profile-manager***).
Mainly used in *CSS classes*, *URLs* and *HTML data attributes*.
Here you can check more example of *kebab-case* [kebab-case](https://developer.mozilla.org/en-US/docs/Glossary/Kebab_case).
***

**CONSTANT_CASE**: Also known as *Screaming Snake Case*. All uppercase letters with words separated by underscores (e.g., ***MAX_RETRY_LIMIT***). 
Used for global constants or configuration flags.
Here you can check more example of *CONSTANT_CASE* [CONSTANT_CASE](https://es-toolkit.dev/reference/string/constantCase.html).
